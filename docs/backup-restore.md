# 备份与恢复

完整备份必须同时包含：

1. SQLite 数据库的一致性备份。
2. 本地对象目录或 S3 bucket 中的文件内容。
3. `workdir/secrets/` 中的 DPAPI 密钥文件；它们只能由原 Windows 用户解密。
4. 实际运行配置及反向代理配置。

仅复制 SQLite 文件不等于备份分享内容。运行中不要直接复制 WAL 数据库文件；使用 SharePipe 的在线备份目录或停机后复制数据库、`-wal` 和 `-shm` 的一致集合。

恢复演练应在隔离目录完成：先恢复数据库和密钥，再恢复对象内容，使用不同端口启动，检查健康状态、管理入口、分享目录树、单文件 Range、ZIP、下载计数和清理任务。确认无误前不要替换生产目录。
